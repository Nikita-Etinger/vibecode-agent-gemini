# Vibecode Agent Bridge (Zero-Click Autonomous Loop)

Автономный агент разработки для Windows, связывающий веб-интерфейс **Google Gemini** с локальной средой выполнения (PyCharm, CLI) через Chrome Extension (Manifest V3) и локальный HTTP-сервер.

Инструмент полностью устраняет ручной перенос файлов и трейсбэков: агент сам применяет дифференциальные патчи, валидирует синтаксис через AST, запускает модульные тесты и при сбоях автоматически возвращает промпт с ошибкой обратно в веб-чат.

## Ключевые возможности

- **Антидубликация и защита от зацикливания (SHA-256):** Каноническая нормализация JSON (`sort_keys=True`) и вычисление SHA-256 хеша с 30-секундным плавающим окном дедупликации. Семафор `is_busy` блокирует параллельные или повторные сетевые вызовы при ре-сканировании истории чата браузером.
- **Fail-Safe Browser Dispatcher & Logging:** Фоновый скрипт `background.js` (Manifest V3) изолированно доставляет промпты во вкладку (`sendPromptToTab`) с автопоиском активного окна Gemini, перехватом необработанных сбоев промисов (`unhandledrejection`, `event.preventDefault()`), валидацией полезной нагрузки (`extractAgentPayload`) и сквозной записью логов в `main.log`.
- **Zero-Click Feedback Loop:** при падении `pytest` агент перехватывает `stderr`, упавший тест и снимок файла, собирает реверс-промпт и через расширение отправляет его обратно в чат без кликов со стороны пользователя.
- **Search / Replace Block Matching:** точечные правки вместо переписывания файлов с нуля исключают потерю контекста и галлюцинации LLM на больших скриптах.
- **Pre-Flight AST Validation:** синтаксис проверяется через модуль `ast.parse()` в оперативной памяти перед сохранением на диск. Ошибки отступов и скобок отсекаются до модификации файлов.
- **Windows-First Native Integration:** декодирование вывода консоли (`cp866`), динамическое добавление путей Python Scripts в `PATH` подпроцессов.
- **Auto-pip Dependency Resolver:** при `ModuleNotFoundError` агент автоматически определяет недостающую библиотеку и устанавливает её через текущий интерпретатор.

## Быстрый старт

### 1. Установка расширения в Chrome
1. Откройте `chrome://extensions/`.
2. Включите **«Режим разработчика»** (вверху справа).
3. Нажмите **«Загрузить распакованное»** и выберите папку `chrome_extension`.

### 2. Запуск локального агента
Дважды кликните по файлу `start.bat` или выполните в консоли:
```cmd
python main.py
```
В логе агента появится сообщение:
`[*] Zero-Click API мост слушает 127.0.0.1:5050`

### 3. Работа в браузере
1. Скопируйте системный промпт из файла `SYSTEM_PROMPT.md` и отправьте его первым сообщением в новый чат с Gemini.
2. Поставьте модели любую задачу разработки.
3. Выделите сгенерированный блок JSON в ответе модели.
4. Нажмите **ПКМ ➔ «Запустить Zero-Click Loop»**.
5. Агент применит код, прогонит тесты и при ошибках сам автоматически отправит исправления в чат до зеленого статуса.
