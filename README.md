# Vibecode Agent Bridge (Zero-Click Autonomous Loop)

Автономный инженерный агент разработки для Windows 11, связывающий веб-интерфейсы **Google Gemini**, **OpenAI ChatGPT** и **chat.z.ai** с локальной средой выполнения (Python 3.10+, PyCharm, CLI) через браузерные расширения (Chrome Extensions Manifest V3) и локальный HTTP-мост на порту 5050.

Инструмент полностью устраняет ручной перенос файлов и трейсбэков: агент сам применяет дифференциальные патчи, валидирует синтаксис через AST, запускает модульные тесты `pytest` и при сбоях автоматически возвращает сжатый промпт с ошибкой обратно в веб-чат до успешного прохождения.

```text
+-------------------------------------------------------------------------+
|               Web Interfaces (Gemini / ChatGPT / chat.z.ai)            |

                                     |

                                     v
+-------------------------------------------------------------------------+
|                         Local Python Agent (main.py)                    |
|   - Дедупликация и валидация входящих JSON-пейлоадов                   |

+-------------------------------------------------------------------------+
```

## Поддерживаемые расширения (Manifest V3)

В репозитории представлены три независимых расширения под разные веб-интерфейсы:

1. **`chrome_extension_gemini/`** — адаптация под кастомные веб-компоненты Google Gemini (`<code-block>`, `rich-textarea`).
2. **`chrome_extension_chatgpt/`** — интеграция с интерфейсом ChatGPT (`pre code`, `#prompt-textarea`).
3. **`chrome_extension_zai/`** — интеграция с `chat.z.ai` на базе редактора CodeMirror 6 (`.cm-content`, `textarea#chat-input`).

### Установка в Chrome / Edge / Brave:
1. Перейдите по адресу `chrome://extensions/`.
2. Включите **«Режим разработчика»** (Developer Mode) в верхнем правом углу.
3. Нажмите **«Загрузить распакованное расширение»** (Load unpacked).
4. Выберите нужную директорию (`chrome_extension_gemini`, `chrome_extension_chatgpt` или `chrome_extension_zai`).

## Встроенный инструментарий (`tools/`)

* **`code_search.py` (Контекстный поиск по проекту):**
  * `search_text(query, root_dir, ...)` — быстрый полнотекстовый и regex-поиск с фильтрацией мусорных папок (`.git`, `__pycache__`, `.venv`, `node_modules`). Выдает номера строк и локальный контекст.
  * `find_definitions(symbol_name, root_dir)` — точечный поиск объявлений классов и функций (`def`, `class`).
  * `get_directory_tree(root_dir, max_depth)` — построение компактного дерева каталогов проекта.
* **`error_compressor.py` (Умное сжатие логов):**
  * Очистка ANSI escape-последовательностей.
  * Автоматическая фильтрация кадров трассировки стандартных библиотек и `site-packages`, сохраняющая только стек проекта.
  * Head+Tail усечение больших логов и снимков кода для защиты веб-интерфейсов от зависаний (лимит ~1200–1800 символов).
* **`hid_controller.py`:**
  * Безопасная эмуляция ввода через буфер обмена (`paste`) без рассинхрона системных раскладок.
  * Закрепление окон поверх остальных (`pin_window`) для предотвращения троттлинга таймеров.
* **`vision_ocr.py`:**
  * Оптическое распознавание экранных элементов и получение точных координат клика.

## Быстрый запуск

```cmd
:: Клонирование репозитория
git clone git@github.com:Nikita-Etinger/vibecode-agent-gemini.git
cd vibecode-agent-gemini

:: Установка зависимостей
pip install -r requirements.txt

:: Запуск агента
start.bat
```
