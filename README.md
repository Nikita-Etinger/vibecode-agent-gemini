# Vibecode Agent Bridge (Zero-Click Autonomous Loop)

Автономный инженерный агент разработки для Windows 11, связывающий веб-интерфейсы **Google Gemini** и **OpenAI ChatGPT** с локальной средой выполнения (PyCharm, CLI) через Chrome Extensions (Manifest V3) и локальный FastAPI HTTP-сервер.

Инструмент полностью устраняет ручной перенос файлов и трейсбеков: агент сам применяет дифференциальные патчи, валидирует синтаксис через AST, запускает модульные тесты и при сбоях автоматически возвращает промпт с ошибкой обратно в веб-чат до успешного прохождения.

## Ключевые возможности

- **Zero-Click Feedback Loop:** при падении `pytest` агент перехватывает `stderr`, упавший тест и снимок файла, собирает реверс-промпт и через расширение отправляет его обратно в чат без кликов со стороны пользователя.
- **Двусторонняя поддержка Gemini и ChatGPT:** выделенные расширения с автопарсингом блоков кода и неформатированного JSON из текстовых ответов модели.
- **Search / Replace Block Matching:** точечные правки вместо переписывания файлов с нуля исключают потерю контекста и галлюцинации LLM на больших скриптах.
- **Pre-Flight AST Validation:** синтаксис проверяется через модуль `ast.parse()` в оперативной памяти перед сохранением на диск. Ошибки отступов и скобок отсекаются до модификации файлов.
- **Системный инструментарий (tools/):**
  - `hid_controller.py`: защита от рассинхрона раскладок через вставку буфера обмена (`paste`), удержание окна браузера активным через WinAPI (`pin_window`), эмуляция кликов и шорткатов.
  - `vision_ocr.py`: получение экранных координат UI-элементов через оптическое распознавание текста.
- **Изоляция проектов (`workspace/`):** ядро агента `BaseAgent/` остается неприкосновенным, все целевые файлы, тесты и артефакты создаются строго в изолированных директориях.
- **Windows-First Native Integration:** декодирование вывода консоли (`cp866`), динамическое добавление путей Python Scripts в `PATH` подпроцессов.
- **Auto-pip Dependency Resolver:** при `ModuleNotFoundError` агент автоматически определяет недостающую библиотеку и устанавливает её через текущий интерпретатор.

## Быстрый старт

### 1. Установка расширений в Chrome
1. Откройте `chrome://extensions/`.
2. Включите **«Режим разработчика»** (вверху справа).
3. Нажмите **«Загрузить распакованное расширение»** и выберите нужную папку:
   - `chrome_extension_gemini` для Gemini;
   - `chrome_extension_chatgpt` для ChatGPT.

### 2. Запуск локального агента
Дважды кликните по файлу `start.bat` или выполните в консоли:
```cmd
python main.py
```
Сервер запустится по адресу: `http://127.0.0.1:5050`.

### 3. Работа в браузере
1. Откройте диалог с Gemini (`gemini.google.com`) или ChatGPT (`chatgpt.com`).
2. При генерации ответа нажмите появившуюся кнопку **«Агент»** в блоке кода (или выделите JSON и нажмите **ПКМ → «Запустить Zero-Click Loop»**).
3. Агент применит код, прогонит тесты и при необходимости сам отправит ошибки на исправление до успешного прохождения.
